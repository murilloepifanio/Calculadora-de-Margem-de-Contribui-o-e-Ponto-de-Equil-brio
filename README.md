# Calculadora de Margem de Contribuição e Ponto de Equilíbrio

Projeto educacional em Python de Murillo Epifânio Rodrigues de Almeida.

## Execução

Execute `python main.py` no terminal. Não são necessárias dependências externas.

## Entradas

Preço de venda unitário, custo variável unitário, despesas fixas do mês e quantidade vendida.

## Indicadores

- Margem unitária = preço - custo variável unitário.
- Ponto de equilíbrio = arredondamento para cima de despesas fixas / margem unitária.
- Receita = preço x quantidade.
- Resultado simplificado = receita - custo variável total - despesas fixas.

## Exemplo

Com preço de R$ 35, custo variável de R$ 14, despesas fixas de R$ 420 e 30 unidades, a margem é R$ 21, o ponto de equilíbrio é 20 unidades e o resultado simplificado é R$ 210.

O resultado simplificado não é necessariamente o lucro líquido: podem faltar tributos e outros custos ou despesas.
